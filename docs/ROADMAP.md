# Roadmap

## Phase 0 — Discovery and planning

Repository assessment and product/technical documentation. Complete for this empty repository.

## Phase 1 — Foundation

Workspace, strict TypeScript, configuration, PostgreSQL migrations, seed framework, auth/RBAC foundation, API error handling, logging, base UI tokens/components, health checks, and test harness.

## Phase 2 — Customer core

Auth screens, profile/dependents/addresses, service catalog, quote and booking creation, sandbox checkout, booking history.

## Phase 3 — Provider core

Onboarding, profile, service areas, availability, documents, verification statuses, request acceptance, active-service actions, earnings view.

## Phase 4 — Booking operations

Matching module, assignment, event timeline, cancellations/rescheduling, notification events.

## Phase 5 — Family and safety

Shared family dashboard, scoped location session abstraction, incident/emergency workflow, support cases.

## Phase 6 — Admin and polish

Verification/admin operations, payments/refunds, analytics, responsive/accessibility pass, hardening and release checks.

## Future

Production KYC/background checks, real maps/ETA, provider payouts, push/WhatsApp, recurring care, mobile apps, advanced risk scoring, and multi-region scale.
