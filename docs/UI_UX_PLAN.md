# UI/UX Plan

## Experience principles

Calm, premium, human, transparent, and operationally clear. Every booking surface shows the service, time, duration, estimate/price, provider verification, current status, next action, support, and emergency path where relevant.

## Surfaces

- Public landing page: value, how it works, service categories, trust, safety, FAQ, demo-labeled testimonials, CTA.
- Customer: overview, booking wizard, active timeline/map card, family/dependents, history, invoices, notifications, support.
- Provider: today, requests, active service, verification, availability, earnings, reviews, incidents, support.
- Admin: segmented operations navigation for verification, bookings, users, payments, incidents, support, analytics.

## Design system

Central tokens for ink, cream, surface, brand, success, warning, danger, typography scale, spacing, radii, shadows, motion, and breakpoints. Reusable Button, Input, Select, Modal, Drawer, Card, Badge, Avatar, Timeline, Status, MapCard, BookingCard, ProviderCard, Review, Empty, Error, Skeleton, Toast, and Confirmation components.

## Accessibility and responsive behavior

Semantic HTML, labels, keyboard navigation, visible focus, contrast, accessible dialogs, inline validation, reduced-motion support, and mobile-first booking/provider action flows. Admin prioritizes desktop but remains usable on tablet/mobile.
